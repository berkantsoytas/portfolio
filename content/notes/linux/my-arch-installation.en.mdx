## 5. Disk Partitioning

> **Layout**: 1GB EFI boot / 16GB swap / remaining ext4 root

Identify the target disk:

```bash
lsblk
```

Partition with cfdisk (interactive, easy):

```bash
cfdisk /dev/nvme0n1
```

**cfdisk steps:**

| Step                        | Action                                       |
| --------------------------- | -------------------------------------------- |
| Select GPT label            | Select `[gpt]`                                |
| Partition 1 (EFI)           | `[New]` → size: `1G` → type: `EFI System`    |
| Partition 2 (Swap)          | `[New]` → size: `16G` → type: `Linux swap`   |
| Partition 3 (Root)          | `[New]` → size: (rest) → type: `Linux filesystem` |
| Write & exit                | `[Write]` → `yes` → `[Quit]`                 |

## 8. CachyOS Repo & Base Installation

Install both the **stock Arch kernel** (`linux`) and **CachyOS kernel** (`linux-cachyos`). CachyOS is optimized for better desktop performance; the stock kernel stays as a fallback.

First, add the CachyOS repository:

```bash
pacman -Sy
pacman -S --noconfirm archlinux-keyring

pacman -S --noconfirm cachyos-keyring
```

Add the CachyOS repo config (manual):

```bash
cat >> /etc/pacman.conf << 'EOF'
[cachyos]
Server = https://mirror.cachyos.org/repo/x86_64/$repo
SigLevel = Optional TrustAll
EOF
```

Install the base system (`-K` optimizes the kernel for your hardware):

```bash
pacstrap -K /mnt base base-devel \
  linux linux-headers \
  linux-cachyos linux-cachyos-headers \
  linux-firmware sof-firmware cachyos-mirrorlist \
  amd-ucode intel-ucode \
  iwd networkmanager \
  vim nano sudo fish firefox \
  git htop btop neofetch \
  sddm plasma-desktop \
  dolphin konsole kate
```

> `intel-ucode` — Intel processor microcode updates.
> `sof-firmware` — Intel audio (Sound Open Firmware) support.
> `plasma-desktop` — KDE desktop environment.
> `sddm` — KDE's display manager.

## 13. Hostname

The hostname identifies your machine on the network. The `hosts` file is required for localhost resolution — without it some applications (e.g., X11, sudo) may experience delays.

```bash
echo "yoga-arch" > /etc/hostname

cat >> /etc/hosts << 'EOF'
127.0.0.1   localhost
::1         localhost
127.0.1.1   yoga-arch.localdomain yoga-arch
EOF
```

## 17. Bootloader — systemd-boot

```bash
bootctl install
```

**Create the bootloader entry.** We identify the root partition by PARTUUID — even if the disk order changes (e.g., `/dev/nvme0n1p3` → `/dev/sda1`), the system will still boot.

```bash
cat > /boot/loader/entries/arch.conf << 'EOF'
title   Arch Linux (CachyOS)
linux   /vmlinuz-linux-cachyos
initrd  /intel-ucode.img
initrd  /initramfs-linux-cachyos.img
options root=PARTUUID=<ROOT_PARTUUID> rw nvidia_drm.modeset=1
EOF
```

> The `linux` line uses the `linux-cachyos` kernel. You can also add `vmlinuz-linux` as a fallback entry.

**Find PARTUUID and paste it into `arch.conf`:**

```bash
blkid -s PARTUUID -o value /dev/nvme0n1p3

```

Optionally verify the installation with:

```bash
bootctl status
```

**Loader config:**

```bash
cat > /boot/loader/loader.conf << 'EOF'
default arch.conf
timeout 4
editor no
EOF
```

## 18. NVIDIA Driver Installation (580.173.02)

```bash
pacman -S nvidia-dkms nvidia-utils nvidia-settings nvidia-prime
```

Verify the driver version:

```bash
modinfo nvidia | grep ^version
```

> Current version: **580.173.02**

### NVIDIA Kernel Parameters

Added to the `options` line in `/boot/loader/entries/arch.conf`:

```
nvidia_drm.modeset=1
```

### NVIDIA Hook (mkinitcpio)

Already added in `/etc/mkinitcpio.conf`:

```
MODULES=(nvidia nvidia_modeset nvidia_uvm nvidia_drm)
```
