## 5. Disk Bölümleme

> **Layout**: 1GB EFI boot / 16GB swap / gerisi ext4 root

Diski belirle:

```bash
lsblk
```

cfdisk ile bölümle (interaktif, kolay):

```bash
cfdisk /dev/nvme0n1
```

**cfdisk adımları:**

| Adım                        | İşlem                                        |
| --------------------------- | -------------------------------------------- |
| GPT label seç               | `[gpt]` seç                                  |
| 1. bölüm (EFI)              | `[New]` → size: `1G` → type: `EFI System`    |
| 2. bölüm (Swap)             | `[New]` → size: `16G` → type: `Linux swap`   |
| 3. bölüm (Root)             | `[New]` → size: (kalan) → type: `Linux filesystem` |
| Yaz ve çık                  | `[Write]` → `yes` → `[Quit]`                 |

## 8. CachyOS Repo Ekleme & Base Kurulum

Hem **standart Arch çekirdeği** (`linux`) hem de **CachyOS çekirdeği** (`linux-cachyos`) birlikte kurulacak. CachyOS daha iyi masaüstü performansı için optimize edilmiştir, standart Arch çekirdeği ise yedek olarak kalır.

Önce CachyOS reposunu ekle:

```bash
pacman -Sy
pacman -S --noconfirm archlinux-keyring

pacman -S --noconfirm cachyos-keyring
```

CachyOS repo config'i (manuel):

```bash
cat >> /etc/pacman.conf << 'EOF'
[cachyos]
Server = https://mirror.cachyos.org/repo/x86_64/$repo
SigLevel = Optional TrustAll
EOF
```

Temel sistemi kur (`-K` ile donanıma göre optimize edilmiş kernel):

```bash
pacstrap -K /mnt base base-devel \
  linux linux-headers \
  linux-cachyos linux-cachyos-headers \
  linux-firmware sof-firmware cachyos-mirrorlist \
  amd-ucode intel-ucode \
  iwd networkmanager \
  vim nano sudo fish firefox \
  git htop btop neofetch \
  sddm plasma-desktop \
  dolphin konsole kate
```

> `intel-ucode` — Intel işlemci mikro kod güncellemeleri.
> `sof-firmware` — Intel ses (Sound Open Firmware) desteği.
> `plasma-desktop` — KDE masaüstü ortamı.
> `sddm` — KDE'nin display manager'ı.

## 13. Hostname

Makine adı (hostname), ağ üzerinde cihazın tanınmasını sağlar. `hosts` dosyası ise localhost çözümlemesi için gereklidir — onsuz bazı uygulamalar (ör. X11, sudo) gecikmeli çalışabilir.

```bash
echo "yoga-arch" > /etc/hostname

cat >> /etc/hosts << 'EOF'
127.0.0.1   localhost
::1         localhost
127.0.1.1   yoga-arch.localdomain yoga-arch
EOF
```

## 17. Bootloader — systemd-boot

```bash
bootctl install
```

**Bootloader girişini oluştur.** Root bölümünü PARTUUID ile tanımlıyoruz — disk sırası değişse bile (`/dev/nvme0n1p3` → `/dev/sda1` gibi) sistem açılır.

```bash
cat > /boot/loader/entries/arch.conf << 'EOF'
title   Arch Linux (CachyOS)
linux   /vmlinuz-linux-cachyos
initrd  /intel-ucode.img
initrd  /initramfs-linux-cachyos.img
options root=PARTUUID=<ROOT_PARTUUID> rw nvidia_drm.modeset=1
EOF
```

> `linux` satırında kullanılacak çekirdek: `linux-cachyos`. Yedek olarak `vmlinuz-linux` da eklenebilir.

**PARTUUID'yi bul ve `arch.conf` içine yaz:**

```bash
blkid -s PARTUUID -o value /dev/nvme0n1p3

```

Alternatif olarak `bootctl status` ile kurulumu doğrula:

```bash
bootctl status
```

**Loader config:**

```bash
cat > /boot/loader/loader.conf << 'EOF'
default arch.conf
timeout 4
editor no
EOF
```

## 18. NVIDIA Driver Kurulumu (580.173.02)

```bash
pacman -S nvidia-dkms nvidia-utils nvidia-settings nvidia-prime
```

Driver versiyonunu doğrulamak için:

```bash
modinfo nvidia | grep ^version
```

> Güncel sürüm: **580.173.02**

### NVIDIA Kernel Parametreleri

`/boot/loader/entries/arch.conf` içinde `options` satırına eklendi:

```
nvidia_drm.modeset=1
```

### NVIDIA Hook (mkinitcpio)

`/etc/mkinitcpio.conf` dosyasında daha önce eklendi:

```
MODULES=(nvidia nvidia_modeset nvidia_uvm nvidia_drm)
```
