---
title: "Git Temel Komutlar"
---

## Başlangıç

```bash
git init
git clone <url>
```

## Günlük İşlemler

```bash
git add <file>       # staging
git commit -m "mesaj" # commit
git push              # remote'a gönder
git pull              # remote'dan çek
```

## Branch İşlemleri

```bash
git branch           # branch listele
git checkout -b <isim> # yeni branch oluştur ve geç
git merge <branch>   # branch'i birleştir
```

## Durum Kontrolü

```bash
git status
git diff
git log --oneline --graph
```
